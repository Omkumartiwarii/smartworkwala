## 🚀 How to Deploy on Render

### Method 1: Deploy as a Static Site (Recommended & 100% Free)
1. Go to [Render Dashboard](https://dashboard.render.com).
2. Click **New +** and select **Static Site**.
3. Connect your GitHub repository: `Omkumartiwarii/smartworkwala`.
4. Configure the settings:
   - **Name**: `smartworkwala`
   - **Branch**: `main`
   - **Build Command**: *(leave empty)*
   - **Publish Directory**: `.` (or `./`)
5. Click **Create Static Site**. Your site will be live in seconds with free SSL!

### Method 2: Automatic Blueprint
Render automatically detects `render.yaml` if you choose **New + -> Blueprint**.

## 💻 Local Development

Simply open `index.html` in your browser, or run a local web server:

```bash
# Python
python -m http.server 8000

# Node.js (npx)
npx serve .
```

Open `http://localhost:8000` in your web browser.
